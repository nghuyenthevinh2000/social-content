# LinkedIn Story Formats

Add story format files to this folder for LinkedIn-specific post structures.

Each format file should cover:

- **When to use this format** — the type of story or goal it suits
- **Structure** — the specific section breakdown (hook, body, CTA, etc.)
- **Length guidelines** — character or line count targets
- **Platform conventions** — what LinkedIn readers expect (line breaks, white space, hashtags, etc.)
- **Example skeleton** — a fill-in-the-blank structural template
- **Common mistakes for this format** — what kills engagement on LinkedIn specifically

## Suggested formats to add

| Format | Description |
|:-------|:------------|
| `single-hook-post.md` | One powerful hook, short body, punchy close. Most common LinkedIn post type. |
| `carousel.md` | Multi-slide visual story. Slide 1 = hook, middle = value, last = CTA. |
| `transformation-arc.md` | Before/after narrative. Flaw → cost → turning point → insight. |
| `list-story.md` | Numbered lessons learned, each grounded in a real scene. |
| `contrarian-take.md` | Opens by contradicting a widely-held belief, then earns the alternative view. |
