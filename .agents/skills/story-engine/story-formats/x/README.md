# X (Twitter) Story Formats

Add story format files to this folder for X-specific post structures.

Each format file should cover:

- **When to use this format** — the type of story or goal it suits
- **Structure** — section breakdown and tweet sequencing
- **Length guidelines** — character limits, thread length
- **Platform conventions** — what X readers expect (punchy language, no wasted words, thread hooks, engagement patterns)
- **Example skeleton** — a fill-in-the-blank structural template
- **Common mistakes for this format** — what kills reach on X specifically

## Suggested formats to add

| Format | Description |
|:-------|:------------|
| `single-tweet.md` | One tweet, 280 chars. Hook is the entire post. No room for warmup. |
| `short-thread.md` | 3–6 tweets. Tweet 1 = hook, tweets 2–5 = scenes/points, final = punch close. |
| `long-thread.md` | 7–20 tweets. Full story arc. Each tweet must work as a standalone hook. |
| `quote-tweet-story.md` | Reacting to someone else's tweet with a personal story that deepens the conversation. |
