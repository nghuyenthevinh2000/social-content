# Instagram Story Formats

Add story format files to this folder for Instagram-specific post structures.

Each format file should cover:

- **When to use this format** — the type of story or goal it suits
- **Structure** — caption layout, image/reel relationship to copy
- **Length guidelines** — caption length, line break rhythm
- **Platform conventions** — what Instagram readers expect (visual-first, first-line hook visible before "more", hashtag placement, emoji usage)
- **Example skeleton** — a fill-in-the-blank structural template
- **Common mistakes for this format** — what kills engagement on Instagram specifically

## Suggested formats to add

| Format | Description |
|:-------|:------------|
| `caption-story.md` | Short caption (under 150 chars visible before "more") that hooks and expands. |
| `long-caption.md` | Full story in the caption — scene-by-scene, paragraph breaks as visual rest. |
| `carousel-caption.md` | Paired with a carousel; caption primes emotion, slides carry the story. |
| `reel-script.md` | Spoken or text-on-screen script for short video. Hook in first 2 seconds. |
| `story-sequence.md` | Multi-story sequence (Instagram Stories). Each story = one beat or scene. |
