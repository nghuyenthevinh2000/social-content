# Other Platform Story Formats

Add story format files to this folder for platforms not covered by the named platform folders.

Examples: YouTube descriptions, podcast show notes, newsletter issues, Substack posts, TikTok scripts, email sequences.

Each format file should cover:

- **When to use this format** — the type of story or goal it suits
- **Platform name and context** — what platform and audience this serves
- **Structure** — section breakdown
- **Length guidelines** — character, word, or time targets
- **Platform conventions** — what readers or viewers expect on this platform
- **Example skeleton** — a fill-in-the-blank structural template
- **Common mistakes for this format** — what kills engagement specifically here

## Suggested formats to add

| Format | Description |
|:-------|:------------|
| `newsletter-story.md` | Email/Substack. Subject line as hook. Conversational tone. One idea per issue. |
| `youtube-description.md` | First 2 lines visible before "show more". Hook + context + links. |
| `podcast-intro.md` | Spoken cold open. Scene-based. No context before conflict. |
| `tiktok-script.md` | Hook in first 1–2 seconds (text or spoken). Story beats every 3–5 seconds. |
| `email-sequence.md` | Multi-email story arc. Each email = one scene or revelation. |
