# Infographic layout templates

Select a structure here, then follow the [infographic skill workflow](../SKILL.md) for approval, output sizing, authoring, and screenshot capture. Each template folder contains `design.md` (content slots and layout rules), `index.html` (source HTML), and `output.png` (preview). Source dimensions and example commands in template docs are references; the skill's 16:9 landscape or 9:16 portrait canvas and chosen output directory take precedence.

| Template | Source format | Structure | Best for |
|---|---|---|---|
| [Business plan summary](business-plan-summary-report/design.md) | A4 portrait (900 × 1273 px) | Bold headline, hanging brand banner, overview and findings, three goal cards, audience table, three-bar chart | Business plans, GTM launches, three-pillar proposals |
| [Enterprise architecture stack](enterprise-architecture-stack/design.md) | Wide landscape (1618 × 752 px) | Left boundary axis, four-tier stack (Apps, Capabilities, Services, Infrastructure), structured component blocks | IT architecture, AI platforms, microservices, cloud topologies |
| [Executive summary report](executive-summary-report/design.md) | A4 portrait (900 × 1273 px) | Wave watermark, pill headers, two-column narrative and findings, goal items, bar chart | Executive briefings, board reports, program reviews |
| [Financial performance report](financial-performance-report/design.md) | A4 portrait (900 × 1273 px) | Wave arches, highlight cards, four-metric KPI banner, expense chart, notes | Earnings, P&L updates, budgets |
| [Monthly social media report](monthly-social-media-report/design.md) | A4 portrait (900 × 1273 px) | Split header, KPI boxes, trend chart, featured posts, demographic bars, regional donut | Marketing performance, audience growth, campaign engagement |
