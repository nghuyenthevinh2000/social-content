# Cost Profiling & Transcript Leak Remediation Plan

```text
User Action (keyword | profile | reel | video)
  -> cost_control.cost_scope(user_id, action, job_id)
  -> cost_control.check_call_allowed() [Action Allowlist + URL Guard + Budget Cap]
  -> cost_control.run_glasser_tracked() / record_cost_event() [Parse Charge + Run ID + Cache Hit]
  -> PostgreSQL cost_events + Job Summary -> Per-User & Per-Action Reports
```

## 2. Centralized Module Design: `tools/app/backend/cost_control.py`

| Responsibility | Public Primitives in `cost_control.py` | Behavior & Enforcement Rules |
|---|---|---|
| 1. Separation from `profiling.py` | Standalone `tools/app/backend/cost_control.py` (always active in production; `profiling.py` remains opt-in latency/memory benchmarking via `PROFILE_BACKEND=1`). | Cost tracking, endpoint policy guards, and budget circuit breakers must never be disabled when performance profiling is off. |
| 2. Context propagation across threads | `cost_scope(user_id, action, job_id=None, sheet_slug=None)`, `current_cost_scope()`, `submit_with_context(executor, fn, *args, **kwargs)`. | Uses `contextvars.ContextVar` to bind `user_id`, `action` (`keyword_search`, `profile_research`, `reel_research`, `video_generation`), `job_id`, and live counters (`api_calls`, `cache_hits`, `wasted_calls`, `cost_micro`). `submit_with_context` copies context into `ThreadPoolExecutor` workers in `video_search.py` and `transcriber/glasser.py`. |
| 3. Pre-call policy & URL guards | `check_call_allowed(provider, endpoint, payload=None, sub_action=None)` $\rightarrow$ raises `CostPolicyError` or returns `(allowed: bool, reason: str)`. | - **`keyword_search` allowlist**: allows only search endpoints (`/v1/youtube/search`, `/videos`, `/v1/facebook/adLibrary/search/ads`, `/v1/tiktok/search/keyword`, `/v2/instagram/reels/search`); **hard-blocks** `/v1/facebook/post/transcript`.<br>- **Transcript URL guard**: blocks `/v1/facebook/post/transcript` unless `payload["url"]` matches `facebook.com/reel/<id>`, `facebook.com/.../videos/<id>`, or `facebook.com/watch/?v=<id>`. |
| 4. Per-action budget circuit breakers | `ACTION_BUDGETS` dict enforced inside `check_call_allowed()`:<br>- `keyword_search`: max `18` API calls, `35_000` micro-USD (`$0.035`)/sheet<br>- `profile_research`: max `3` transcript calls/sheet, `100_000` micro-USD (`$0.10`)/sheet<br>- `reel_research`: max `1` transcript call/reel, `10_000` micro-USD (`$0.01`)/reel<br>- `video_generation`: max `2` Omni calls/job | Halts runaway loops before executing the subprocess when a scope exceeds `max_calls`, `max_transcript_calls`, or `max_cost_micro`. |
| 5. Unified Glasser runner & stdout parser | `run_glasser_tracked(provider, endpoint, version, payload, idempotency_key, out_file, task_id=None, timeout=45.0, sub_action=None)` + `parse_glasser_stdout(text)`. | Runs `check_call_allowed()`, executes `glasser run`, parses `Run ID:`, `Run URL:`, `Response: HTTP (\d+)`, and `Charge:\s*\$([0-9.]+)\s*(?:\(([^)]+)\))?` via `decimal.Decimal` $\rightarrow$ exact integer `cost_micro` ($1\text{ USD} = 10^6\text{ micro-USD}$), flags `wasted = (http_status >= 400 or (charge_clause == 'NO_RESULT' and cost_micro > 0))`, and logs to `cost_events`. |
| 6. Non-Glasser & cache event recording | `record_cost_event(provider, endpoint, cost_micro=0, cache_hit=False, wasted=False, sub_action=None, run_id=None, run_url=None, http_status=200, charge_clause=None, duration_ms=0.0)`. | Records cache hits (`cost_micro=0, cache_hit=True`), blocked wasted calls, Google GenAI Omni video generation (`provider="google_genai"`, `cost_micro=job["cost"]`), and ACP agent calls (`provider="acp"`, `duration_ms`). |
| 7. Query & CLI reporting (`CostControlStore`) | `COST_STORE.get_user_summary(user_id, days=30)`, `COST_STORE.get_all_users_summary(days=30)`, `COST_STORE.get_job_summary(job_id)`, and `python3 tools/app/backend/cost_control.py`. | Aggregates spend per user profile (`JOIN user_profiles`, `user_credits`), per action, and per endpoint, plus a Wasted Call Audit table. |

## 4. Schema, API & CLI Surface

| Surface | Specification | Purpose |
|---|---|---|
| PostgreSQL table (`schema.sql`) | `CREATE TABLE IF NOT EXISTS cost_events (id BIGSERIAL PRIMARY KEY, user_id TEXT NOT NULL, action TEXT NOT NULL, sub_action TEXT, job_id TEXT, sheet_slug TEXT, provider TEXT NOT NULL, endpoint TEXT NOT NULL, run_id TEXT, run_url TEXT, http_status INTEGER, cache_hit BOOLEAN NOT NULL DEFAULT FALSE, wasted BOOLEAN NOT NULL DEFAULT FALSE, cost_micro BIGINT NOT NULL DEFAULT 0, charge_usd TEXT NOT NULL DEFAULT '0.000000', charge_clause TEXT, duration_ms DOUBLE PRECISION DEFAULT 0.0, created_at TEXT NOT NULL);` with indexes on `(user_id, created_at DESC)`, `(action, created_at DESC)`, and `(job_id)`. | Persistent, queryable ledger of every paid, cached, or blocked call per user profile and action. |
| Per-user & per-action API (`server.py`) | `GET /api/costs/summary?days=30` (authenticated): delegates to `COST_STORE.get_user_summary(user_id, days)` joining `cost_events`, `user_profiles`, and `user_credits` to return:<br>1. `user_profile`: `{user_id, name, gender, age, credit_balance_usd}`<br>2. `by_action`: `[{action, jobs_count, api_calls, cache_hits, wasted_calls, cost_micro, cost_usd, avg_cost_per_job_usd}]`<br>3. `by_endpoint`: `[{provider, endpoint, api_calls, cache_hits, wasted_calls, cost_micro, cost_usd}]`<br>4. `recent_runs`: latest 50 events with `run_url` citations. | Exposes per-user profile and per-action cost breakdown to the frontend and admins. |
| Job-level cost summary (`research.py`) | Wrap `_process_sheet()` in `with cost_control.cost_scope(user_id, action, job_id, sheet["slug"]) as cscope:` and store `sheet["cost_summary"] = cscope.to_dict()` in `jobs.data` and `runs/<job_id>/result.json`. | Attaches exact cost (`cost_usd`, `api_calls`, `cache_hits`, `wasted_calls`, `run_urls`) to every job sheet. |
| CLI reporter (`cost_control.py`) | `python3 tools/app/backend/cost_control.py [--user <uid>] [--action <act>] [--days 7]`: queries `cost_events` and prints Markdown tables for (1) Spend per User Profile, (2) Spend per Action, (3) Endpoint Cache Efficiency, and (4) Wasted / Blocked Call Audit. | Direct CLI command to audit spend per user profile and action. |
