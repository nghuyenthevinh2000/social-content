# Same-content group comparison

| Stage | Rule |
| --- | --- |
| Identity | Record stable group/copy IDs and permalinks; names and matching captions alone are not reliable identities. |
| Eligibility | Compare identical creative at matched visible ages. Pending, rejected, removed and missing placements are operational gaps, not bottom-ranked audience results. |
| Ranking | First compare qualified inquiries and next steps where coverage is known; otherwise label rankings distribution-only using reported viewers and attention. Preserve ties. |
| Cross-content | Compare common eligible rounds first; do not pool raw views from unequal content ages. Never sum group viewers as unique audience reach. |
| Focus | Retest stronger relevant placements while retaining comparison groups. One good result is not permanent proof. |
| Reduce | Repeatedly weak comparable exposure can justify less testing effort, but unknown inquiry data cannot establish zero sales. |
| Pause | Require repeated weak outcomes, verified inquiry coverage, relevant alternatives, resolved visibility issues and explicit owner approval. |
| Re-entry | Retest when audience fit, moderation, season or application changes; retain historical evidence. |

```text
Same creative → Verify visibility → Match age → Rank eligible copies → Review allocation
```

| Placement record | Fields |
| --- | --- |
| Identity | Content/version, original Post ID, group ID/URL, copy ID/permalink. |
| Status/time | Submitted, approved/visible, first seen, observed, timezone and confidence. First seen is not automatically approval time. |
| Metrics | Views, viewers, impressions, three-second views, watch time, qualified actions and attribution certainty. Preserve nulls. |
| Decision | Evidence references, eligible round count, focus/retest/reduce/pause proposal, rationale and review date. |

| Policy / storage | Requirement |
| --- | --- |
| Review minimum | A project may adopt three matched rounds before allocation review as an operating policy, not statistical proof. No universal winning threshold. |
| Sources | Check whether exports actually contain group identifiers. If not, use separately captured group rows; do not attribute original Page totals to groups. |
| Worked comparisons | Store project-specific matrices under `<project>/loop/`, not the shared tool. |
| Actions | A recommendation does not authorize leaving groups, deleting posts, following accounts or publishing. |
