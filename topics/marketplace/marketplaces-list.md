# The Complete Directory of Online Marketplaces for Digital Goods, Extensions & Micro-SaaS

A curated, categorized guide to online marketplaces where creators, developers, and founders buy, sell, and distribute digital products.

---

## 1. Asset & Micro-SaaS Acquisitions (Buy & Sell Entire Businesses / Codebases)
*Where founders buy, sell, or exit digital tools, browser extensions, apps, and micro-SaaS projects.*

| Marketplace | Primary Focus | Revenue Verification / Model | Key Highlights |
| :--- | :--- | :--- | :--- |
| **[TrustMRR](https://trustmrr.com)** | Bootstrapped SaaS & Extensions | Live Stripe / Lemon Squeezy API | Tamper-proof MRR/ARR verification directly from payment gateways; low 3% platform fee. |
| **[Acquire.com](https://acquire.com)** | Scaled Micro-SaaS, Extensions & Startups | Live integrations + Due diligence | The standard for bootstrapped tech exits; escrow assistance, private deal rooms, buyer verification. |
| **[Microns.io](https://microns.io)** | Sub-$100k Deals & Indie Projects | Curated newsletter & listings | Tailored specifically for indie hacker micro-acquisitions; 0% commission for sellers. |
| **[Flippa](https://flippa.com)** | High-liquidity open marketplace | Verified financials + Open bidding | Dedicated search filters for browser extensions, apps, and content sites; massive global buyer pool. |
| **[SideProjectors](https://www.sideprojectors.com)** | Side-projects, Codebases & MVPs | Direct buyer-seller peer messaging | Free to list; ideal for hobby projects, starter extensions, or projects without regular MRR. |
| **[IndieMaker](https://indiemaker.co)** | Indie hacker community projects | Escrow-backed deals | Buy/sell side projects, micro-tools, domains, and extensions. |
| **[Tiny Acquisitions](https://tinyacquisitions.com)** | Micro-projects under $100k (often <$10k) | Direct buyer-seller deals | Focused on lean digital projects, niche directories, and single-purpose extensions. |

## 3. Host-App & Software Extension Directories (Publish & Monetize)
*Official and community directories where users discover and install extensions directly into host apps.*

### Productivity & Developer Tool Extensions
* **[Obsidian Community Plugins](https://obsidian.md/plugins)** & **[Obsidian Hub](https://www.obsidiandirectory.com/)**: Built-in plugin store for Obsidian; monetized via companion SaaS backends, GitHub Sponsors, or license unlocking.
* **[Raycast Store](https://www.raycast.com/store)**: Fast-growing macOS launcher extension store with developer SDKs, fast deployment, and an active developer base.
* **[VS Code Marketplace](https://marketplace.visualstudio.com/VSCode)** / **[Open VSX Registry](https://open-vsx.org/)**: Premier developer editor ecosystems with millions of active users.
* **[Alfred Gallery](https://alfred.app/)**: Official hub for macOS automation workflows and tools.
* **[Figma Community](https://www.figma.com/community)**: Hub for plugins, widgets, and design systems; natively supports paid subscriptions and one-time fees via Stripe.
* **[Shopify App Store](https://apps.shopify.com/)**: Highest ARPU app marketplace for merchant tools and e-commerce extensions.
* **[WordPress Plugin Directory](https://wordpress.org/plugins/)**: The massive open-source CMS directory, typically monetized via freemium tiers.

### Browser Extension Web Stores
* **[Chrome Web Store](https://chromewebstore.google.com/)**: Standard distribution reaching over 3B Chromium users across Google Chrome, Brave, Arc, Opera, and Edge.
* **[Firefox Browser Add-ons (AMO)](https://addons.mozilla.org/)**: Mozilla’s official directory with built-in review and open-web security standards.
* **[Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/)**: Dedicated store for enterprise and Windows users with lower developer competition.
