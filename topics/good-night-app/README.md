# 🌙 Good Night - Minimal Sleep Counter (Mobile Web App)

A serene, distraction-free bedtime companion designed to help you fall asleep. Built with an ultra-minimalist Zen aesthetic and responsive **up-down vertical swipe** mechanics.

---

## ✨ Features

- **Vertical Up-Down Swipe & Scroll**:
  - **Swipe Up or Down** anywhere on the screen (or roll trackpad/mouse wheel) to count.
  - Swiping up launches the item floating peacefully into the moonlit sky with soft stardust trails.
  - Swiping down sends the item drifting gently across the twilight canvas.
- **Ultra-Minimal, Calm Interface**:
  - Completely decluttered: No busy button grids, no bulky widgets, no visual noise.
  - Elegant large typography showing only the count and item description (`sheep jumped`, `bills stacked`, etc.).
  - Glowing ambient moon and twinkling stars.
- **Customizable Items via Discrete Bottom Sheet**:
  - Tap the subtle bottom pill (`[ 🐑 Fluffy Sheep ••• ]`) to switch between:
    - 🐑 **Sheep** (*Fluffy sheep jumps*)
    - 💵 **Cash** (*Counting dollar bills*)
    - ⭐ **Stars** (*Cosmic wish glow*)
    - 🐱 **Cats** (*Sleepy purring kittens*)
    - ☁️ **Clouds** (*Drifting dream clouds*)
    - 💤 **Zzz** (*Breaths and deep sleep*)
    - ✍️ **Custom Emoji Input** (set any emoji & name you want).
- **Soothing Audio & Haptics**:
  - Gentle pentatonic kalimba chime synthesizer via Web Audio API.
  - Discreet mute toggle in the top-right corner.
  - Subtle tactile haptics on mobile devices.
